# AcademySoft TETRIS (1986) — восстановленный исходный код

**Оригинальный советский Тетрис 1986 года, авторы А. Пажитнов и В. Герасимов (AcademySoft, СССР)**  
Восстановлен методом реверс-инжиниринга оригинального `TETRIS.COM` (24245 байт).  
Портирован на **Turbo Pascal 7** (оригинал — Turbo Pascal 3.0).

## Требования

Игра работает **только под MS-DOS** (или в эмуляторе DOS) — это не порт под современные ОС.

Код напрямую работает с железом IBM PC:

- прямая запись в видеопамять `$B800` / `$B000` (сохранение и восстановление экрана);
- чтение области данных BIOS `$0040:$0049` (видеорежим) и `$0040:$0060` (курсор);
- прерывание `INT 10h` для управления курсором;
- переключение текстовых режимов 40 / 80 колонок и монохромного MDA;
- модуль `Crt` реального режима: `Sound`, `Delay`, `ReadKey`;
- 6-байтный `Real` из Turbo Pascal — от него зависит формат файла рекордов.

Под Windows и Linux напрямую не запустится.
